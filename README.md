# fly —— 苍蝇博主跟踪与每日要点

## 我每天要做的两件事

**1. 丢东西进来**

- 新文章链接 → `数据源/苍蝇的二级市场-8月.txt`、`数据源/苍蝇的五级市场-8月.txt`（每行 `月.日 链接`）
- 群聊截图 → `群聊/待处理/`（直接丢，不用改名）
- 持仓有变动 → 改 `数据源/持仓.json`

**2. 说一句「告诉我今天该关注什么」**

产出落在 `每日要点/<日期>.md`。**收盘后（15:00 之后）说才拿得到收盘价。**

想单独整理截图，就说「按 md 总结截图」。

## 目录

```
指南1-交易风格与策略体系.md   他六年的方法论（长期沉淀，不常改）
指南2-每日交易要点SOP.md      每日流程和输出格式（改流程改这里）
持仓.example.json             持仓格式模板，复制成 数据源/持仓.json 再填

数据源/    文章链接 txt、文章总表 xlsx、持仓.json、持仓截图   ← 不进 git
群聊/      待处理/ · 已归档/ ← 不进 git；总结/ · 如何总结群聊截图.md ← 进 git
docs/      抓下来的文章原文                                   ← 不进 git
docs_clean/  清洗后的文章（读文章读这个）                     ← 不进 git
每日要点/  每天的产出，按日期归档
分析产出/  月度初筛 / 阶段整合（指南1 的原料）
脚本/      ma.py · fetch_all.py · clean_docs.py
```

**为什么有些目录不进 git**：这个仓库是公开的。`数据源/` 有实际持仓、成本和融资负债，
`群聊/已归档/` 有群友的头像和昵称，`docs/` 是抓取的他人公众号原文。这些只留在本地，
`.gitignore` 里各一行，想放开删掉对应行即可。

## 脚本

在 `fly/` 目录下跑，三个脚本都用绝对路径定位，从哪个目录调都行。

```bash
# 行情：收盘价 + MA5/10/21/34 + 偏离度 + 20日高低
python3 脚本/ma.py                 # 全部持仓
python3 脚本/ma.py 600893 302132   # 指定代码

# 抓文章（已下载的自动跳过）
python3 脚本/fetch_all.py --from-txt 数据源/苍蝇的二级市场-8月.txt --account 苍蝇的二级市场
python3 脚本/fetch_all.py --from-txt 数据源/苍蝇的五级市场-8月.txt --account 苍蝇的五级市场

# 清洗：docs/ → docs_clean/（原文不动）
python3 脚本/clean_docs.py
```

纯标准库，不需要装任何东西。`ma.py` 偶尔会被东财限流，隔几分钟重跑失败的那个代码。

首次使用：`cp 持仓.example.json 数据源/持仓.json`，把股数和成本填成自己的。
